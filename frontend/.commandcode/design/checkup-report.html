// PRIORITY ISSUES
P0

Export CSV is broken

Riwayat.tsx navigates via window.location.href to /api/predictions/export/. The axios client attaches the JWT, but a raw navigation does not. Backend ExportView requires IsAuthenticated with SimpleJWT, so the download 401s and the interceptor bounces the user to /login.

FIX: fetch the CSV through api.get(..., { responseType: "blob" }), create an object URL, and trigger a programmatic <a download> click.
P0

Headline metric the UI refutes

The Akurasi Model card leads with R2 while the Top Produk card on the same grid admits product-level accuracy is ~25%. The hero number overstates the prediction quality a daily user should trust.

FIX: relabel honestly ("Akurasi model revenue"), promote the caveat into the evaluation context, and give model freshness equal footing.
P1

No search, filter, or pagination

useTransaksi and useCustomer hard-code ?page_size=100. Rows beyond 100 silently disappear from the UI as the ledger grows.

FIX: /design surface - search input, pagination or load-more, and a visible "showing X of Y" count.
